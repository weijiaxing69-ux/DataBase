- 在独立临时实例加载完整 V1.4 DDL 和 seed；`90_验收查询.sql` 检查 65 张表、1900 行基线数据，四类历史支付/计费/结算一致性检查均为 0。课程数据中的 L01 期望应付 6.00 元、L02 期望金额 6.00 元均与验收查询一致。

- 六条复杂查询（每题两种写法）均执行成功；三组写法在测试数据上分别返回相同的 20 行。MySQL 8.4.13 对六条查询执行 `EXPLAIN ANALYZE` 均成功。
- 10 项数据库实连 API 检查通过：管理员和车主登录、当前账号、账号列表、资料/车辆/优惠券/活动查询、手机号脱敏、模拟充值与流水查询、登出撤销会话。
- 会员函数的真实数据库事务检查通过：L01 券锁幂等、未付清拒绝核销、付清只核销一次；车队授权、额度重复预占/结算幂等、跨月调整留痕、超额转人工复核和释放幂等；钱包扣款/退款余额与流水原子一致、回调幂等；发券过程成功/超限回滚、钱包流水更新/删除被触发器阻止。
- 并发检查通过：两笔 200 元车队预占竞争 300 元额度只允许一笔；两笔 150 元钱包扣款竞争约 200 元余额只允许一笔，另一笔因余额不足失败并通过退款恢复余额；剩余一张活动券被两个请求同时领取时只发出一张。

## 接入与运行

1. 使用组长的统一初始化脚本，在隔离的 MySQL 8.0.16+ 测试库建立完整项目表、外键和 seed；按 `database/modules/membership/README.md` 加载会员权限、视图、过程、触发器。
2. 按 `backend/README.md` 配置 `backend/.env` 中的隔离测试库地址和随机密钥，然后启动 FastAPI。
3. 在 `frontend/member4/` 安装依赖并运行开发服务器。Vite 将 `/api/v1` 代理到 `http://127.0.0.1:8000`；OpenAPI 页面为 `/docs`。
4. 与成员2联调时，同一个 SQLAlchemy Session 传给车队授权、额度、优惠券和钱包辅助函数；由订单/支付/退款顶层服务管理事务提交或回滚。
